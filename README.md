# Refugio de Animales

Simulación de un día en un refugio de animales utilizando Python.

## Requisitos
- Python 
- cowsay

## Instalación
```bash
git clone https://github.com/sofiaaacuellarrr/refugio-cuellar.git
cd refugio-cuellar
pip install -r requirements.txt
```

## Ejecución
```bash
python main.py
```
